# Armies-of-Starbies
I have designed my own printed circuit board inspired by TAWOG(The Amazing World of Gumball)'s episode The Console.
It will have an outer case for the physical circuit board.

# What I used:
-> KiCad's PCB editor
-> KiCad's Schematic editor
-> Piskel (to make sprite)
-> Image2cpp
